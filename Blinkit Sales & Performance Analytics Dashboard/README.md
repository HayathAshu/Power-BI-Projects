# 📊 Blinkit Sales Dashboard | Power BI

An interactive **Blinkit Sales Dashboard** built using **Microsoft Power BI**, designed to analyze sales performance, customer behavior, and outlet efficiency.  
This project was created by **referring to a YouTube tutorial** and enhanced with my own understanding of data analysis, KPIs, and visualization best practices.

---

## 🛠️ Project Objective

The main goal of this project is to:

- Convert raw Blinkit sales data into **meaningful business insights**
- Build a **dynamic and interactive dashboard**
- Practice **real-world Power BI concepts** such as:
  - Data cleaning
  - DAX measures
  - KPI tracking
  - Business-focused storytelling

---

## 📌 Dashboard KPIs

The dashboard highlights the following **key performance indicators (KPIs):**

- **Total Sales**
- **Average Sales**
- **Number of Items Sold**
- **Average Customer Rating**

These KPIs give a quick overview of overall business performance.

### 📈 Key Insights Generated

- Medium-sized outlets contribute higher overall sales

- Tier-2 cities show strong sales potential

- Certain item categories dominate total revenue

- Customer ratings directly influence average sales

These insights can help businesses optimize inventory planning, outlet expansion, and marketing strategies.
